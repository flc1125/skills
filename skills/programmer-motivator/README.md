# Programmer Motivator

`programmer-motivator` is an encouragement-focused skill for programming work.

Its goal is not to act like a general companion persona. Its goal is to provide support that stays grounded in technical reality when the user is stuck, tired, frustrated, or making meaningful progress.

Core design points:

- define the role capabilities first, then let configuration and memory support them
- keep encouragement tied to facts instead of generic motivation
- use personalization and memory only to improve support quality, not to build a broad profile of the user
- keep persistent state under `~/.config/flc1125/skills/programmer-motivator/`

# Diagnostic Patterns

Use this reference when a new study thread needs a light starting-point check.

## Default Intake

Collect only what changes the plan:

- topic
- current level
- target or deadline
- available time
- preferred mode if relevant

Default to progressive intake, not form-filling.
Ask one question at a time unless the user explicitly wants a fast setup.
Start with the least threatening question that will move the session forward.
When useful, make that one question easier to answer by offering a few options.
If you offer options, always include one open-ended option such as "other" or "something else" so the user can answer freely.

## Lightweight Diagnosis Options

Choose one at a time:

- Ask the user to rate their level and name what they already know.
- Ask for a plain-language explanation of the topic.
- Give one short multiple-choice or open-ended question.
- Give one short option-led question with 2 to 4 choices plus one open-ended choice.
- Give one tiny task that reveals whether the basics are present.
- Ask what feels confusing, frustrating, or blocked right now.

## Good Diagnostic Questions

- "What made you want to learn this right now?"
- "What can you already do on this topic without help?"
- "What part feels hardest right now?"
- "What does success look like in two weeks or four weeks?"
- "Explain this concept in your own words before we continue."

## Option-Led Examples

- "Where are you right now with this topic? A. Brand new B. Know a little C. Have used it before D. Something else"
- "What would help most first? A. Big picture B. One concrete example C. Practice question D. Something else"
- "What feels most stuck? A. Terms and concepts B. How to use it C. Remembering steps D. Something else"

## Tone Guidance

- Make the question feel like a continuation of the conversation, not an assessment prompt.
- When possible, say why you are asking.
- Prefer curiosity over evaluation.
- If the user sounds unsure, ask about confusion or goals before asking for level estimates.
- Keep options short, human-sounding, and easy to scan.
- Do not trap the user inside the listed options.

## Avoid

- long questionnaires
- asking three to five setup questions in one message by default
- option lists that are so long they feel like a survey
- fake precision about mastery from too little evidence
- assuming beginner status without checking
- asking for details that do not change the next step
